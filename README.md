# 경영정보 질문 도구 (내부용)

ERP에서 내려받은 **분개장**과 현장 **거래내역** 엑셀을 올리면, 대표가 자주 묻는 경영 질문에 한 줄 답과 근거 표를 보여주는 정적 웹 도구입니다. 서버 없이 `index.html`을 브라우저로 열면 됩니다.

## 입력

| 파일 | 필수 | 내용 |
|---|---|---|
| 분개장 | 필수 | ERP의 분개장(전표 전체) 엑셀. 여러 해를 한꺼번에 올려도 됩니다 |
| 거래내역 | 선택 | `templates/거래내역_템플릿.xlsx` 형식. 건별 수량·단가·금액 (단가, 물량, 변동비 계산에 사용) |
| 업체마스터 | 선택 | `templates/업체마스터_템플릿.xlsx` 형식. 같은 업체의 다른 표기(별칭), 결제기한 |

## 답할 수 있는 질문

1. 이 업체에 이번 달 얼마, 언제 줘야 해? (예정일은 업체마스터 결제기한 또는 과거 결제 이력 평균으로 추정)
2. 이 업체 이번 달에 돈 들어왔어?
3. 이번 달에 나갈 돈과 들어올 돈
4. 이 비용은 뭐야? (계정·거래처·적요)
5. 이 비용은 이번 달에 왜 이렇게 많이 나갔어?
6. 이번 달 이익(손실)
7. 줄일 수 있는 비용 항목 (후보 제시 수준)
8. 이익으로 전환하려면 매출이 얼마나 더 필요한지 (BEP)
9. 현재 통장 잔액 (기준일 잔액을 한 번 입력해야 함)
10. 이 업체 단가와 실제 청구 일치 여부
11. 이 업체 이번 달 물량

모든 숫자는 `js/analysis.js`가 계산하고, `js/questions.js`는 문장과 표만 만듭니다. (나중에 AI 대화 층을 붙일 때 AI가 숫자를 직접 계산하지 않고 이 함수들을 호출하도록 하기 위한 구조입니다.)

## 구조

```
index.html          화면
js/util.js          공통 유틸 (날짜, 거래처명 통일)
js/adapters.js      엑셀 → 표준 모델 (분개장, 거래내역, 업체마스터)
js/model.js         표준 모델 구성, 계정 분류
js/analysis.js      손익, 채권·채무(FIFO), 단가, 대조, BEP
js/questions.js     질문별 답변 생성
js/app.js           업로드와 화면 동작
tools/make_templates.py   엑셀 템플릿 생성 (python3 + openpyxl)
```

## 가정과 한계

- **분개장 형식:** 더존 계열 분개장(전표일자, 전표번호, 구분, Code, 계정과목, 차변, 대변, 거래처, 적요)과 계정코드 체계(4xx 매출, 5~7xx 제조원가, 8xx 판관비, 9xx 영업외)를 가정합니다. 다른 ERP는 어댑터 보완이 필요합니다.
- **결산 예상 조정:** 감가상각·퇴직급여·충당부채·주식보상·이자 정산처럼 분기 말에만 입력되는 비용이 아직 없는 분기는 직전 결산 분기(최대 2개) 평균으로 추정해 "결산 예상 반영" 손익에 더합니다. 진행 중인 분기는 경과 일수만큼만 반영하며, 화면의 체크박스로 끌 수 있습니다. 결산 전표가 분개장에 들어오면 자동으로 실제 값으로 대체됩니다. BEP 계산에서는 이 비용들을 분기 평균 월할로 반영합니다. 신규 설비 완공 등으로 실제 감가상각이 달라지면 오차가 생깁니다.
- **결산 전표:** 구분이 `결차/결대`인 전표 중 제조원가 계정의 대변은 재공품 대체로 보고 발생비용에서 제외합니다. 이 때문에 월별 "발생비용 기준" 손익은 ERP 손익계산서와 다를 수 있습니다.
- **기초 잔액:** 분개장 시작 이전의 잔액은 알 수 없습니다. 이전 연도 채무를 갚은 업체는 잔액이 마이너스로 나오며, 이 경우 경고하고 계산에서 제외합니다. 통장 잔액은 기준일 잔액을 입력받아 계산합니다.
- **결제 예정일:** 실제 지급 결정이 아니라 과거 이력 또는 업체마스터 결제기한 기준의 추정입니다.
- **거래내역과 분개장 대조:** 청구처가 다른 경우 템플릿의 `청구처` 칸에 정산 업체를 적어야 업체별 대조가 맞습니다.
- 라이브러리(xlsx, Chart.js)는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 데이터 취급

- 파일은 브라우저 안에서만 처리되며 어디로도 전송되지 않습니다.
- 브라우저에 저장되는 것은 통장 기준 잔액 입력값뿐입니다.
- **실제 분개장, 거래내역, 급여대장, 비밀번호가 들어 있는 시트는 이 저장소에 커밋하지 마세요.**
