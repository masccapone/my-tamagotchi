# 경영정보 대시보드 (내부용)

WEHAGO에서 내려받은 엑셀을 브라우저에 올리면 손익, 손익분기(BEP), 톤당 수익성을 보여주는 단일 HTML 도구입니다.

## 사용법

1. `index.html`을 브라우저에서 엽니다. (인터넷 연결 필요: 엑셀 파서와 차트 라이브러리를 CDN에서 불러옵니다.)
2. 아래 파일을 올립니다. 형식은 자동으로 구분합니다.
   - 월별 손익계산서 (필수)
   - 월별 제조원가명세서 (권장)
   - 폐기물 반입 대장 `처리인계서(반입)` 시트 (선택, 톤당 분석용)
3. 고정비/변동비 분류는 표에서 직접 바꿀 수 있습니다. 초기값은 계정과목 이름으로 추정한 초안입니다.

## 데이터 취급

- 파일은 브라우저 안에서만 처리되며 어디로도 전송되지 않습니다.
- 브라우저에 저장되는 것은 고정비/변동비 분류 설정뿐입니다.
- **실제 재무 파일, 급여대장, 비밀번호가 들어 있는 시트는 이 저장소에 커밋하지 마세요.**

## 알려진 한계

- 손익계산서의 월별 매출원가가 분기·반기에 몰아서 반영되면 월별 손익이 왜곡됩니다. 화면에서 해당 월에 경고를 표시하고, 발생비용(제조원가명세서 + 판관비 + 영업외비용) 기준 손익을 함께 보여줍니다.
- 미수금/미지급금 에이징과 거래처별 단가는 아직 없습니다. 거래처원장, 매입매출전표 엑셀이 필요합니다.
