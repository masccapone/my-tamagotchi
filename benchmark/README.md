# 대결 시험: 이 도구 vs 일반 AI에 파일을 올려 묻기

같은 파일, 같은 질문 20개로 정확도, 시간, 일관성을 비교합니다.

## 질문 세트

- `--set A`: 처음 만든 20문항. 도구를 고치는 과정에서 본 문항이라 **점수가 부풀려져 있음**.
- `--set B`: 같은 의도를 다른 말로 묻는 문항. 규칙을 만들 때 문장을 봤으므로 이 역시 부풀려져 있음.
- `--set C`: 구어체, 줄임말, 동의어. 규칙을 만든 뒤 따로 쓴 문항이며 점수를 보기 전에는 고치지 않았음. **일반화 수준의 참고값**.
- 도구 쪽 점수는 자동 채점(제목+주의 문구에서 정답을 찾음)이라 사람이 매기는 일반 AI 채점과 기준이 완전히 같지는 않음.
- 새 질문 세트를 쓰려면 `build_benchmark.js` 에서 `SET === 'C'` 블록을 복사해 `D` 로 추가.

## 준비

1. 시험 생성 (정답과 질문지가 만들어집니다. **출력 폴더에는 회사 숫자가 들어 있으니 저장소에 올리지 마세요**).
   ```
   node benchmark/build_benchmark.js --journal 분개장1.xlsx 분개장2.xlsx --trades 거래내역또는현황.xlsx --out 시험폴더
   ```
2. 정답은 도구의 분석 함수를 쓰지 않고 원본 행에서 다시 계산한 값입니다(`독립계산_대조.txt` 참고).

## 진행

1. 일반 AI(비교할 서비스)에 같은 엑셀 파일들을 올리고 `질문지_일반AI용.md` 의 안내문을 보냅니다.
2. 질문을 한 번에 하나씩 보내고, 보낸 시각과 답을 받은 시각을 기록합니다.
3. 5개 정도는 새 대화에서 2번 더 반복해 일관성을 봅니다.
4. `채점시트.csv` 에 AI명, 답, 시간, 점수(0, 1, 2)를 적습니다. 채점 기준은 `정답표.csv` 에 있습니다. 도구와 일반 AI를 **같은 사람이 같은 기준으로** 채점해야 공정합니다.
5. 결과 집계:
   ```
   node benchmark/summarize.js 채점시트.csv
   ```

## 공정하게 하려면

- 도구의 점수는 개발자가 매기면 후하게 줄 수 있으니, 가능하면 제3자가 채점하세요.
- 도구를 시험 질문에 맞춰 고치면 점수가 올라가므로, **고친 뒤에는 새 질문(대표가 실제로 묻는 말)으로 다시 시험**하세요.
- 일반 AI에 재무 파일을 올리면 외부로 전송됩니다. 마스킹하거나 회사 방침을 확인하세요.
- 일반 AI의 모델과 버전, 파일 가공 여부(열 이름 정리 등)를 기록하세요.
