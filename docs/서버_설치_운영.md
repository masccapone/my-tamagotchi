# 로컬 서버 설치·운영 안내 (1단계 버전)

경리가 올린 엑셀을 회사 PC 폴더에 저장하고, 대표가 사내 웹 화면에서 질문하는 서버입니다.

> **주의:** 이 버전은 리눅스에서만 시험했고 **Windows에서는 아직 시험하지 못했습니다.** 자동 시작, 자동 업데이트, 설치 파일은 2단계에서 만듭니다. 사내망 안에서만 쓰세요. 인터넷에 직접 열면 안 됩니다(통신이 암호화되지 않습니다).

## 준비물

- 항상 켜 둘 수 있는 Windows PC 1대
- Node.js LTS (18 이상) 설치: https://nodejs.org

## 설치와 시작

1. 이 저장소 폴더를 서버 PC에 복사합니다. (예: `C:\경영도구`)
2. `서버시작.bat` 을 더블클릭합니다.
3. 처음 실행하면 **대표용, 경리용 비밀번호가 자동으로 만들어져** 화면과 `data\초기비밀번호.txt` 에 표시됩니다. 각자에게 전달한 뒤 이 파일을 지웁니다.
4. 화면에 나온 `사내 다른 PC: http://192.168.x.x:3000` 주소를 경리와 대표에게 알려 줍니다.
5. 다른 PC에서 접속이 안 되면 Windows 방화벽에서 Node.js의 사설망 접속을 허용합니다.

## 사용 방법

- **경리:** 경리 비밀번호로 로그인 → 분개장·거래내역 엑셀을 올림 → **서버에 저장**을 누름. 올릴 때마다 이전 저장본은 자동으로 보관됩니다(최근 30개).
- **대표:** 대표 비밀번호로 로그인 → 질문 입력창에 질문하거나 질문 버튼을 누름. 파일 업로드 화면은 보이지 않습니다.
- 질문과 답은 기준일, 확정·잠정·추정 구분과 함께 표시됩니다.

## 비밀번호 바꾸기

```
node server\server.js --set-password boss 새비밀번호8자이상
node server\server.js --set-password accountant 새비밀번호8자이상
```

비밀번호를 5번 틀리면 그 PC는 5분간 로그인할 수 없습니다. 모든 비밀번호를 새로 만들려면 `--reset-passwords` 를 붙여 실행합니다.

## 저장되는 것 (`data` 폴더)

| 파일/폴더 | 내용 |
|---|---|
| `current.json` | 현재 분석용 저장본 |
| `snapshots\` | 이전 저장본(최근 30개) |
| `uploads\` | 경리가 올린 원본 엑셀 |
| `settings.json` | 통장 기준 잔액 |
| `logs\audit-YYYY-MM.jsonl` | 감사 로그: 로그인, 저장, 업로드, 질문(질문 문장 포함), 사용한 데이터·분석 로직 버전 |
| `logs\server.log` | 서버 운영 로그 |
| `config.json` | 비밀번호(암호화된 형태) |

**백업:** `data` 폴더를 통째로 복사해 두면 됩니다. 이 폴더에는 회사 재무 정보가 들어 있으므로 외부 저장소에 올리지 마세요(저장소의 `.gitignore` 에 제외되어 있습니다).

## 확인용 주소

`http://서버주소:3000/api/health` 로 서버가 살아 있는지, 저장본 버전이 몇인지 볼 수 있습니다. (로그인 없이 열리며 재무 정보는 나오지 않습니다.)

## 알려진 한계 (1단계)

- 서버를 껐다 켜면 모두 다시 로그인해야 합니다.
- PC를 재부팅하면 `서버시작.bat` 을 다시 눌러야 합니다.
- 계정은 대표, 경리 두 종류뿐입니다. 사용자별 계정은 없습니다.
- 통신이 암호화되지 않습니다(HTTP). 사내망에서만 사용하세요.
